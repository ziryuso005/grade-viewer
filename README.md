# Grade Viewer

A simple webpage that displays grades for ASSH 11A across core subjects, 
including a computed average for combined subjects and color-coded 
passing/failing grades.

## Features
- Displays 7 core subjects with Term 1, Term 2, and Term 3 grades
- Automatically calculates each subject's average
- Shows a combined row averaging Effective Communication and Mabisang Komunikasyon
- Color-codes averages green (passing, 75+) or red (failing, below 75)

## Built With
- HTML
- CSS
- JavaScript
